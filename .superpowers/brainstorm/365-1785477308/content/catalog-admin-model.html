用两种商品模板适应不同交易方式，但共享图片、语言、询价和库存状态，避免后台过于复杂。

统一货源状态

客户和业务员使用同一套清晰状态，避免把预订货误认为仓库现货。
草稿 Draft仅后台可见，资料尚未完成。
现货 Ready Stock已确认可售；显示可用数量和最后核实日期。
工厂预订 Factory Booking显示可预订数量、预计交期和最后核实日期。
已售罄 Sold Out详情页保留但禁止询价，可推荐类似货源；管理员可归档。
库存新鲜度：商品必须记录“最后核实日期”。超过管理员设定天数仍未更新时，后台提醒复核；不自动下架，避免误删仍有效货源。

前台目录与筛选

移动端使用筛选抽屉，桌面端可同时显示筛选栏和商品网格。
整批货 / 单款现货 / 工厂预订品类男 / 女 / 童 / 混合季节采购单位MOQ价格区间最新上架
第一版不做：按目的国强制限制商品。市场落地页只负责推荐和 SEO，所有客户仍能浏览完整货源目录。

双语内容流程

English · 人工录入标题、简介、质量说明和交易备注；品类、状态等使用标准字段。
→
العربية · 自动初稿系统生成阿语，业务员预览 RTL 页面并可修改；确认后与英文一起发布。
安全规则：价格、数量、MOQ、交期等关键数字不由翻译模型改写；固定服装术语优先使用人工维护词库。
