设计第 4 部分：架构、异常处理与质量保障

首版采用单体 Web 应用与模块化边界：部署简单、成本可控，同时让目录、内容、询价和线索彼此独立。

系统架构

具体技术框架在实施计划中根据现有团队与部署条件选择；设计先固定职责和数据边界。
海外客户前台英语 LTR / 阿语 RTL；手机优先；商品目录、详情、询价清单和信任内容。
搜索与分享入口Google、WhatsApp / 社媒链接、展会二维码和市场落地页。
⇄
Web 应用页面渲染、语言路由、SEO、身份验证、表单接口与业务规则。
商品目录模块两种商品模板、状态、筛选、价格策略与最后核实日期。
内容与语言模块公司内容、案例、市场页、英语原文、阿语译文与术语词库。
询价与线索模块询价清单、表单、商品快照、分配、销售管道与 CSV 导出。
⇄
关系数据库商品、翻译、媒体元数据、用户、询价、线索状态和操作记录。
对象存储 + CDN商品图片与视频；生成多尺寸图片，面向海外加速。
外部服务阿语翻译、邮件通知、访问统计和 WhatsApp 深链接。
管理后台管理员、编辑、业务员按权限操作；后台不对搜索引擎开放。
架构原则：不为首版拆分微服务。模块通过明确的数据接口协作，未来若询价量或媒体量显著增长，再单独扩展对应模块。

客户可理解的异常处理

商品售罄 / 状态变化清单中明确标记不可询价，保留客户填写内容，并推荐同类货源。
询价提交失败保留清单和已填表单，显示可操作错误；允许重试或复制询价编号后 WhatsApp 联系。
翻译服务失败保存英文草稿并提示稍后重试；不发布缺失阿语的阿语页面，也不伪造翻译。
图片 / 视频加载慢先显示压缩图和加载状态；视频按点击加载，不阻塞商品主要信息。
邮件通知失败询价仍成功写入后台；系统重试通知并向管理员显示失败状态。
重复提交短时间内同一请求返回原询价编号，避免业务员收到重复线索。
阿语布局溢出发布预览提示；前台按钮允许换行，不因 RTL 或长文本遮挡价格和操作。
页面不存在双语 404 页面提供搜索、最新货源和询价入口，不自动跳到无关商品。

安全、隐私与可靠性

后台安全安全密码散列、登录限流、基于角色的权限控制、安全 Cookie、CSRF 防护；管理员和编辑建议启用双因素认证。
输入与媒体安全所有表单在服务端校验；富文本清理防 XSS；上传限制格式和大小，随机文件名，媒体与应用隔离存储。
询价隐私仅收集业务所需信息；隐私同意、保留期限、访问日志和管理员导出权限明确，不把客户联系方式暴露在前台。
备份与监控数据库定期自动备份并演练恢复；监控前台可用性、接口错误、询价失败、邮件失败和存储容量。

测试与验收

单元测试价格展示规则、状态转换、询价有效性、商品快照、语言路由和角色权限。
集成测试发布商品、阿语生成、上传媒体、提交询价、分配线索、通知失败重试和 CSV 导出。
端到端测试手机英文 / 阿语 RTL 完整选货与提交；商品售罄、重复提交、弱网和无 JavaScript 基础浏览。
人工验收真实 Android / iPhone、WhatsApp 内置浏览器、主流桌面浏览器；目标国家网络条件下检查速度。
性能目标：核心页面在目标市场手机网络下尽快显示主要商品内容；图片按尺寸和现代格式加载，视频不自动下载，商品与市场页面可被搜索引擎正确收录。

第一版边界

包含

  • 双语前台与阿语 RTL
  • 整批货 / 单款商品模板
  • 货况优先详情页和可信贸易视觉
  • 多商品询价清单主入口
  • WhatsApp 辅助与提交后跟进
  • 轻量线索后台、分配、统计和导出
  • 公司信任内容、市场落地页、SEO 与分析

暂不包含

  • 客户注册、会员等级和登录后价格
  • 在线支付、订单、合同和物流追踪
  • 供应商入驻与多商家审核
  • 自动运费、库存 ERP 实时同步
  • 完整 CRM、营销自动化与聊天机器人
  • 英语 / 阿语以外的人工维护语言
